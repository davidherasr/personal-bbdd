# Scouting Hub v1.0

Aplicación Streamlit de scouting personal basada en un flujo simple: **partido → minutos/nota/MVP → ranking**.

## Arranque

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

En Streamlit Cloud, el archivo principal es `streamlit_app.py`.

## Qué aporta v1.0

- Mesa para puntuar un once y suplentes desde una sola tabla.
- Precarga de datos al volver a editar un partido.
- Alta de jugadores dentro de la propia tabla.
- Edición individual y edición masiva de jugadores.
- Ranking simple equivalente al Excel y análisis avanzado separado.
- Exportación ZIP y Excel.
- Datos iniciales vacíos.

Consulta `EXCEL_INTEGRATION.md` para ver la correspondencia con el archivo original.
