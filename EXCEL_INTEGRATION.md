# Integración Excel v1.2

La aplicación conserva las vistas principales del archivo original:

- `Hechos_Stats`: una fila por jugador y partido.
- `Dim_Jugadores`: métricas agregadas.
- `Dim_Equipos`: cobertura por equipo.
- `His_Rank`: ranking ordenado.

El Excel estilo BBDD puede descargarse desde **Importar / Exportar**.
