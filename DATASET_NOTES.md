# Dataset inicial Scouting Hub v0.5

Este paquete incluye una estructura inicial para arrancar la app sin la base vacía:

- Países: principales nacionalidades y mercados.
- Competiciones: top 5 ligas europeas, segundas divisiones grandes y Primeira Liga.
- Equipos: equipos de esas competiciones 2025/26 como base de trabajo.
- Jugadores: paquete semilla curado, especialmente clubes grandes y Manchester City.

Importante: las plantillas cambian durante la temporada y los datos de jugadores deben considerarse punto de partida editable, no registro oficial cerrado. La app está preparada para corregir, fusionar duplicados y enriquecer con observaciones propias.

Fuentes públicas consultadas para estructurar competiciones/equipos y validar enfoque:
- Premier League: página oficial de squad Manchester City y Transfermarkt Premier League 25/26.
- LaLiga: páginas oficiales de clubes de LALIGA EA SPORTS y LALIGA HYPERMOTION 2025/26.
- Serie A / Serie B: página oficial Lega Serie A y Transfermarkt Serie B 25/26.
- Bundesliga / 2. Bundesliga: Transfermarkt Bundesliga/2. Bundesliga 25/26.
- Ligue 1 / Ligue 2: referencias públicas de temporada y Transfermarkt Ligue 2 25/26.
- FootballSquads: índice de temporada 2025/26 para top leagues y segundas divisiones.
